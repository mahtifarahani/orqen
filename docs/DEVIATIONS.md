> Historical Rust implementation record. The Go migration supersedes its backend paths, commands and dependency choices; see [GO-MIGRATION.md](GO-MIGRATION.md) and [README](../README.md).

| WP | What | Why |
|---|---|---|
| WP0 | `scripts/dev-mongo.sh start` launches mongod with `nohup ... &` and a pid file instead of `--fork`. | `mongod --fork` is not supported on macOS. |
| WP2 | `with_txn` allows up to 30 attempts with short jittered backoff (plan: 5). | Every event append contends on one counter document; 20 concurrent writers cannot all commit within 5 attempts. |
| WP2 | `ScopedCollection::new` takes `&OrgId` (not `&OrgScope`); `OrgScope` lives in the WP5 extractor. | Avoids a db -> http dependency; same scoping guarantee. |

| WP6 | `run_idempotent` takes `Fn + Send + Sync + 'static` (route closures are `move` and clone owned captures), not `FnMut`. | The boxed transaction future cannot borrow locals (`BoxFuture<'s>` is higher-ranked); the closure is shared via `Arc` across retries. |

| WP12 | Backend fix: `rust-embed` now has the `interpolate-folder-path` feature (workspace `Cargo.toml`) plus a `build.rs` that re-runs on `web/dist` changes; unit test `http::ui::tests::built_ui_is_visible_to_the_embed`. | `$CARGO_MANIFEST_DIR` was taken literally, so with `allow_missing = true` the folder silently "did not exist" and the UI was never served (503) even when built. |
